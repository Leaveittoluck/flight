OVERVIEW
--------
Click quota is now scoped per browser using a persistent anonymous_id stored
in localStorage. Each browser gets its own 5-click/month allowance instead of
all anonymous users sharing one global counter.

--------------------------------------------------------------------------------
HOW THE FLOW WORKS
--------------------------------------------------------------------------------

1. Browser first visit:
   - getAnonymousId() finds nothing in localStorage
   - Generates a UUID, saves as 'litl_anonymous_id', returns it

2. Every CTA click:
   - Frontend reads anonymous_id from localStorage
   - POST /api/click: { destination_id, click_type, anonymous_id }

3. Backend:
   - Validator ensures anonymous_id is a valid UUID
   - Service counts this browser's clicks in the current calendar month
   - If count >= 5: HTTP 429, code: "LIMIT_REACHED"
   - If allowed: INSERT row, return remaining_clicks

4. Each browser now has an independent 5-click quota.
   Clearing localStorage (or switching browsers) starts a fresh quota.
