server/src/validators/destinations.validator.js
  - Zod schema for POST /api/destinations/generate
  - Validated fields:
      departure_airport_id  required integer, positive
      budget                required number, positive
      travellers            required integer, min 1 max 6
      trip_type_slug        required non-empty string
      season                optional string (accepted, not used yet)
  - Exports: validateGenerateRequest(body) -> safeParse result

server/src/services/destinations.service.js
  - Stub service layer
  - generateDestinations(params) returns { request: params }
  - TODO comment marks where real SQL logic goes later

server/src/controllers/destinations.controller.js
  - Thin controller: validates -> calls service -> responds
  - Invalid body: 400 JSON with field-level error list
  - Valid body: 200 JSON with ok/message/data
  - Errors forwarded to global errorHandler via next()

server/src/routes/destinations.routes.js
  - POST /generate -> generate controller

---------------------------------------------------
ENDPOINT
---------------------------------------------------

POST http://localhost:5000/api/destinations/generate
Content-Type: application/json

---------------------------------------------------
TEST: VALID REQUEST
---------------------------------------------------

Body:
{
  "departure_airport_id": 1,
  "budget": 400,
  "travellers": 2,
  "trip_type_slug": "city_break"
}

Expected response (200):
{
  "ok": true,
  "message": "Destination generate route is wired",
  "data": {
    "request": {
      "departure_airport_id": 1,
      "budget": 400,
      "travellers": 2,
      "trip_type_slug": "city_break"
    }
  }
}

---------------------------------------------------
TEST: INVALID REQUEST (missing fields / bad values)
---------------------------------------------------

Body:
{
  "departure_airport_id": "not-a-number",
  "budget": -50,
  "travellers": 10
}

Expected response (400):
{
  "ok": false,
  "message": "Validation failed",
  "errors": [
    { "field": "departure_airport_id", "message": "Expected integer, received string" },
    { "field": "budget", "message": "Number must be greater than 0" },
    { "field": "travellers", "message": "Number must be less than or equal to 6" },
    { "field": "trip_type_slug", "message": "Required" }
  ]
}

HOW TO TEST
---------------------------------------------------

Using curl:

    -H "Content-Type: application/json" \
    -d '{"departure_airport_id":1,"budget":400,"travellers":2,"trip_type_slug":"city_break"}'

Using VS Code REST Client / Thunder Client / Postman:
  POST http://localhost:5000/api/destinations/generate
  Content-Type: application/json

  {
    "departure_airport_id": 1,
    "budget": 400,
    "travellers": 2,
    "trip_type_slug": "city_break"
  }

Run server:
  cd server
