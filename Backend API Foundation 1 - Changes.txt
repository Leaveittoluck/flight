DATE: 2026-04-02

---------------------------------------------------
FILES CREATED
---------------------------------------------------

server/src/controllers/health.controller.js
  - Extracted health check logic from app.js
  - Queries DB with SELECT NOW()
  - Calls next(error) on failure so errorHandler catches it

server/src/routes/health.routes.js
  - Express Router for the health endpoint
  - GET /health -> healthCheck controller

server/src/routes/index.js
  - Central route aggregator
  - All route files are registered here
  - Mounted at /api in app.js

server/src/middleware/notFound.js
  - Catches any request that didn't match a route
  - Returns JSON: { ok: false, message: "Route X not found" }
  - HTTP 404

server/src/middleware/errorHandler.js
  - Global error handler (4-param Express signature)
  - Returns JSON: { ok: false, message: "..." }
  - Uses err.status / err.statusCode, falls back to 500
