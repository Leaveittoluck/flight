CHANGE SUMMARY — CTA Disabled Tooltip
Date: 2026-04-03
Branch: feature/project-scaffold

OVERVIEW
--------
Added hover tooltip and improved visual feedback for CTA buttons when the
monthly click limit is reached. One file changed.

--------------------------------------------------------------------------------
FILE MODIFIED
--------------------------------------------------------------------------------

client/src/components/destinations/DestinationCard.jsx

NEW — CtaTooltip component (local, above resolveCtaError):
  - Absolutely positioned above the button (bottom-full)
  - Hidden by default (opacity-0), fades in on group-hover (opacity-100)
  - transition-opacity duration-150 for smooth appearance
  - pointer-events-none so it never blocks mouse events
  - Arrow using CSS border trick (border-t-slate-800)
  - role="tooltip" for accessibility
  - Only rendered when limitReached === true

CHANGED — CTA button wrappers:
  - Each button wrapped in: <div className="relative group ...">
  - The wrapper (not the button) receives cursor-not-allowed when limitReached
  - This is necessary because disabled buttons do not fire hover/mouse events —
    hover must be captured on the parent element for group-hover to work
  - disabled:pointer-events-none added to buttons (replaces disabled:cursor-not-allowed
    which was on the button itself — now handled by wrapper instead)
  - title={limitReached ? 'Upgrade to continue booking' : undefined} on each button
    for keyboard/screen reader users who don't see the tooltip

UNCHANGED:
  - Click logic (handleCtaClick)
  - API calls
  - limitReached amber message below buttons
  - ctaError red message
  - All existing disabled:opacity-50 styles

--------------------------------------------------------------------------------
TOOLTIP BEHAVIOUR
--------------------------------------------------------------------------------

When limitReached === false:  wrapper is a plain relative div, no tooltip rendered
When limitReached === true:
  - Wrapper gets cursor-not-allowed
  - Button gets title="Upgrade to continue booking" (native fallback)
  - CtaTooltip rendered but invisible (opacity-0)
  - On wrapper hover → group-hover:opacity-100 → tooltip fades in above button
