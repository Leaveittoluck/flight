BUG
---
type="number" inputs natively allow +, -, e, E, and . to be typed even when
only positive whole numbers are wanted.

FIX
---
client/src/components/form/BudgetInput.jsx

Added onKeyDown handler to the input:
  onKeyDown={(e) => {
    if (['-', '+', 'e', 'E', '.'].includes(e.key)) e.preventDefault()
  }}

e.preventDefault() cancels the keystroke before it reaches the input value,
so the character is never inserted. The controlled value, onChange logic,
per-person hint, and validation are all untouched.
