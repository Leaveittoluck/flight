OVERVIEW
--------
Introduced react-router-dom routing, a fixed Navbar, a Layout wrapper, and two
placeholder pages. GeneratorPage and all existing components untouched.

--------------------------------------------------------------------------------
FILES MODIFIED
--------------------------------------------------------------------------------

client/src/App.jsx
  BEFORE: Directly rendered <GeneratorPage />
  AFTER:
  - Wraps the app in <BrowserRouter>
  - Defines three <Route> entries nested inside a shared <Layout> route:
      "/"           → GeneratorPage
      "/dashboard"  → DashboardPage
      "/stats"      → StatsPage
  - Layout renders once at the Route level; all pages inherit Navbar automatically

--------------------------------------------------------------------------------
FILES CREATED
--------------------------------------------------------------------------------

client/src/components/layout/Navbar.jsx
  - Fixed to the top of the viewport (fixed top-0 inset-x-0 z-50 h-14)
  - Left side: "Leave It To Luck" brand text
  - Right side: nav links defined in a NAV_LINKS array (easy to extend)
  - Uses react-router-dom NavLink with `end` prop on "/" to prevent the Home
    link being active on all routes
  - Active link: bg-blue-50 text-blue-700
  - Inactive link: hover:bg-slate-100 hover:text-slate-900 transition
  - Max-width + padding matches GeneratorPage content width (max-w-4xl)

client/src/components/layout/Layout.jsx
  - Renders <Navbar /> then <Outlet /> (the active page)
  - Adds pt-14 to the content wrapper to clear the fixed navbar (h-14 = 56px)
  - All pages automatically get the navbar without any per-page changes

client/src/pages/DashboardPage.jsx
  - Placeholder; matches GeneratorPage's header/main structure for consistency
  - "Coming soon" card with chart emoji

client/src/pages/StatsPage.jsx
  - Placeholder; same structure as DashboardPage
  - "Coming soon" card with graph emoji
