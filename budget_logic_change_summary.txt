OVERVIEW
--------
Changed destination eligibility from "total cost <= budget" to
"flight cost <= budget". Hotel affordability is now computed separately and
returned as advisory data. The UI unlocks the hotel CTA only after the user
has opened the flight search link for that destination.

NEW BUDGET LOGIC
--------------------------------------------------------------------------------

Old:
  eligible = (flight_cost * travellers) + (ceil(travellers/2) * hotel_cost_per_night * nights)
             <= budget

New:
  eligible = (flight_cost * travellers) <= budget

Response shape per destination now includes:
  flight_total_cost:             flight_cost_per_person * travellers
  hotel_rooms_needed:            ceil(travellers / 2)
  hotel_total_cost:              hotel_rooms_needed * hotel_cost_per_night * nights
  remaining_budget_after_flight: budget - flight_total_cost
  hotel_affordable_after_flight: hotel_total_cost <= remaining_budget_after_flight
  total_trip_cost_estimate:      flight_total_cost + hotel_total_cost

Tier fallback structure unchanged:
  Tier 1: exact type,    flight_total_cost <= budget
  Tier 2: exact type,    flight_total_cost <= budget * 1.10
  Tier 3: similar types, flight_total_cost <= budget
  Tier 4: similar types, flight_total_cost <= budget * 1.10

HOW TO TEST
--------------------------------------------------------------------------------

Example payload (POST /api/destinations/generate):
{
  "departure_airport_id": 1,
  "budget": 400,
  "travellers": 2,
  "trip_type_slug": "beach",
  "departure_date": "2025-08-01",
  "return_date": "2025-08-08"
}

With budget=400 and travellers=2, a destination with flight_cost_per_person=42:
  flight_total_cost            = 42 * 2 = 84        ← fits budget, eligible
  hotel_rooms_needed           = ceil(2/2) = 1
  hotel_total_cost             = 1 * 65 * 7 = 455   ← does NOT fit remaining (316)
  remaining_budget_after_flight = 400 - 84 = 316
  hotel_affordable_after_flight = false
  total_trip_cost_estimate      = 84 + 455 = 539

UI behaviour:
  → "Search flights →" button active
  → "Find hotels →" button locked with tooltip "Search flights first to unlock hotels"
  → User clicks flight → link opens, hotel button unlocks
  → Amber message: "£316 left after flights — hotels may exceed your remaining budget"

With budget=1500 (same destination):
  remaining_budget_after_flight = 1500 - 84 = 1416
  hotel_affordable_after_flight = true (455 <= 1416)
  → After flight click: green message "£1416 left after flights — hotels should fit your budget"
